# Ручная проверка VK · 0.2.0

Blink открывает проверку VK внутри приложения и продолжает **тот же** ожидающий запрос после ответа. Автоматического распознавания, решения заданий, передачи в сторонние сервисы или извлечения авторизации из других приложений нет.

## Современная CAPTCHA

Используется официальный [VK ID Web CAPTCHA SDK](https://www.npmjs.com/package/@vkid/captcha) `@vkid/captcha` **2.0.0**, MIT, автор VK ID / V Kontakte LLC. Его UMD bundle включён в `gui/vendor/`; CDN при запуске не используется. Само задание загружается с HTTPS-адреса, который выдал VK для текущего TURN-запроса.

В отдельном непривилегированном окне GTK3/WebKit пользователь выполняет задание мышью или клавиатурой. SDK возвращает success token; Blink передаёт его ядру вместе с исходным ID challenge. Копировать токен вручную не требуется. Дальнейшая успешность авторизации определяется повторным запросом VK, а готовность VPN — транспортом и установкой маршрутов.

SDK запускается через `CaptchaWidget.show({link, captchaType: 1, view: 'block'})`: это путь для готового `redirect_uri`, полученного при API CAPTCHA. Не генерируются собственные сессии, фиктивные sitekey или OAuth-приложения.

## Изображение

Blink загружает изображение по HTTPS, без cookies и перенаправлений, с таймаутом 10 секунд и ограничением 512 КиБ / 4096×4096. Изображение показывается в окне с полем для кода. Пользователь вводит код и нажимает «Продолжить подключение». Если VK прислал одновременно `url` и `image`, выбирается современная проверка, как в Android-клиенте.

## Отмена, срок действия, ошибки

Окно показывает оставшееся время; срок задаёт ядро (до пяти минут). Отмена, закрытие окна и истечение срока прекращают подключение. Закрытие основного приложения закрывает приватный pipe и окно проверки. Старый ответ после отмены/смены подключения не отправляется. При ошибке сети можно повторить загрузку в том же окне или отменить соединение; сертификаты HTTPS не отключаются.

## CLI

`blink connect ID` при наличии рабочего стола и запуске обычным пользователем открывает то же окно автоматически. Права root нужны только процессу TUN, а окно CAPTCHA запускается с правами пользователя. GUI-компоненты должны быть установлены вместе с WebKit.

В headless-сеансе сохраняется JSON-протокол: `captcha` приходит в stdout, ответ `{"command":"captcha","id":"…","kind":"key|token","value":"…"}` принимается stdin. Без графической среды современное интерактивное задание не отображается. Для отдельного окна доступен `blink captcha`: первая строка stdin — JSON challenge; stdout — один приватный JSON-результат. Это не самостоятельная авторизация: нужен актуальный challenge ожидающего запроса.

## Изоляция

- URL ограничен HTTPS-доменами vk.com/vk.ru и их поддоменами; запрещены userinfo, неожиданные порты, fragment, управляющие символы и обратный слеш.
- WebKit использует ephemeral context: cookies/данные сайтов этой проверки не сохраняются в профиль браузера. Локальное хранилище выключено, локальные файлы не доступны, новые окна и запросы разрешений отклоняются.
- SDK и native callback работают только в именованном JS-мире верхнего frame. Обычный JS страницы/iframe не видит native message handler. Сам SDK проверяет origin сообщения и точный iframe.contentWindow.
- Дополнительно проверяются случайный nonce, ID, срок действия, тип и размер ответа. Callback одноразовый, ответ старого поколения подключения игнорируется.
- Challenge, токен и код не попадают в argv, файлы, буфер обмена или журналы. Между обычным пользователем и VPN-процессом используются анонимные pipes.

## Зависимости и проверка

Ubuntu 20.04: GTK3 + WebKit2 4.0. На новых Ubuntu предпочтителен WebKit2 4.1; поддерживаются оба typelib. Пакет устанавливает `python3-gi`, `python3-pil`, `gir1.2-gtk-3.0`, `gir1.2-webkit2-4.1 | gir1.2-webkit2-4.0`.

Проверяются настоящий WebKit/изолированный callback, legacy-картинка, отмена, срок, неверный nonce и официальный JS SDK с поддельными origin/source. В тестах используется синтетическое задание, запрос к живой CAPTCHA блокируется до отправки. Прохождение живого задания VK зависит от его выдачи для действующей подписки и отдельно не подтверждено.
