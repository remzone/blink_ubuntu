# Blink Ubuntu 0.2.1

Готовые пакеты для Ubuntu 20.04 и новее. Каждый включает CLI, GUI и окно ручной проверки подключения.

- `amd64` — Intel/AMD 64-bit.
- `arm64` — ARM 64-bit; собран кросс-компиляцией, запуск на устройстве не проверен.

Проверьте скачанный файл по SHA256SUMS и установите через `sudo apt install ./blink-ubuntu_0.2.1_amd64.deb` (для ARM замените архитектуру). Запуск: `blink gui` или `blink help`.
